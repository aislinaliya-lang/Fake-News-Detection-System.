About the Project

The Fake News Detection System is a basic artificial intelligence project that uses machine learning to classify news text. The system learns patterns from a dataset containing examples of real and fake news. When new text is entered, the trained model predicts which category it is more likely to belong to.

How It Works

01

Enter Text

The user enters a news headline, sentence, or claim.

02

Text Processing

TF-IDF converts the words into numerical features.

03

AI Analysis

Logistic Regression analyzes the learned patterns.

04

Prediction

The system displays REAL or POSSIBLY FAKE.
